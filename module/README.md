# KidsStar – Yuvomi-Modul

Dieser Ordner ist das Yuvomi-Modul (`id: kidsstar`). Er braucht den KidsStar-Dienst, der unter `/api/extensions/kidsstar/` auf derselben Adresse wie Yuvomi erreichbar sein muss. Yuvomis Modulinstallation stellt den Dienst nicht bereit.

Anleitung: https://github.com/FlessingLabs/yuvomi-kidsstar/blob/main/docs/BETRIEB.md
